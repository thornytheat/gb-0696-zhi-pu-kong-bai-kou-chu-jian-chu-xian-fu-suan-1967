# 质谱字段与规则

sample_id保留前导零。kind取standard、blank、equipment_blank、transport_blank、field_blank、sample、control；未分型的blank按设备空白处理。area与internal_area为峰面积。level为标样浓度，单位支持ug/L、mg/L、ng/L；统一为ug/L。dilution必须大于0。

每批每检测项至少3个独立浓度点。最小二乘使用Decimal，分母为零拒绝；斜率非正拒绝。空白按来源分型取同批同项浓度中位数：设备空白用于实验室浓度扣除；运输空白与现场空白不扣进样品，只作采样链签发判据。净浓度允许为负；不能提前截零。稀释后检出限=0.05×倍数。空白限值=0.05 ug/L（空白自身倍数在比较中抵消）。控制样相对误差超过20%阻断。超过标曲响应范围优先于其他质控判断。

复核结论按样品分别给出：实验室浓度（扣设备空白）、检出状态（检出/未检出/低于空白等）、现场采样链能否签发。签发判据：无现场空白记录=来源未分清不可签发；现场空白超限不可签发；运输空白超限不可签发；其余可签发；质控样不适用。每份样品保留对应空白值与进样依据（曲线参数、各来源空白行号、当前空白依据）。

空白依据可切换：equipment、transport、field、combined（全部空白混合中位数，对应旧规则）。切换须覆盖全部含样品的检测项，否则拒绝并保留原签发结论；切换成功后结论须重新复核。原始进样与原始结论永不覆盖，切换以追加层记录，可切回equipment恢复。

重复编号相同内容标DUPLICATE，不同内容标KEY_CONFLICT。采信包括标曲和空白，最终样品数不等于输入采信数。行数对账独立于样品结果数。

同一批次同一分析项内sample_id唯一；相同样品编号可在不同分析项或批次中复用。
